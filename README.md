# ⚓ Flexbox Harbor — מנווט הסירות

משחק אינטרנטי קצר ללימוד ותרגול **CSS Flexbox**. בכל שלב מוצגת הוראה, והשחקן משנה מאפייני Flexbox (`flex-direction`, `justify-content`, `align-items`, `flex-wrap`) דרך תפריטי בחירה, כדי לנווט את הסירות אל האיים שלהן.

בהשראת Flexbox Froggy — עם עיצוב, נושא (נמל וסירות) ושלבים מקוריים.

## איך מריצים
פותחים את `index.html` בדפדפן. אין צורך בהתקנות, שרת או ספריות חיצוניות.

הגרסה החיה (GitHub Pages): _להשלים לאחר הפרסום._

## מבנה הפרויקט
```
flexbox-harbor/
├── index.html          # מבנה הדף (HTML סמנטי)
├── css/
│   └── styles.css      # עיצוב + מבנה Flexbox
└── js/
    ├── levels.js       # הגדרת 10 השלבים (הוראה + פתרון יעד)
    └── app.js          # לוגיקת המשחק, בדיקת פתרון, ניקוד, שמירה
```

## מאפיינים
- 10 שלבים מדורגים, מהפשוט (`justify-content` בלבד) ועד אתגר שמשלב את כל המאפיינים.
- לוח בגודל פנימי **קבוע** (520×520) — כדי שהפתרון יישאר עקבי בכל מסך. במסכים קטנים הלוח מוקטן ויזואלית (scale) תוך שמירה על הגיאומטריה.
- בדיקת פתרון עם משוב הצלחה/טעות, חיווי שלב ("שלב X מתוך 10"), ספירת ניסיונות.
- מערכת ניקוד, שמירת התקדמות ב-`localStorage`, ומעבר חופשי בין שלבים.
- כפתורי איפוס שלב ואיפוס התקדמות כללית.
- פידבק קולי (Web Audio API — ללא קבצים חיצוניים).

## מגבלות טכניות (לפי דרישות המטלה)
HTML, CSS ו-JavaScript בלבד. ללא ספריות JavaScript חיצוניות. ללא CSS Grid — כל הפריסה מבוססת Flexbox.
